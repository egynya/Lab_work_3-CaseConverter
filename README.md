# CaseConverter

Плагин для Visual Studio Code, предназначенный для преобразования идентификаторов между различными стилями именования (camelCase, snake_case, PascalCase, kebab-case).

**Группа:** M3106  
**Среда разработки:** Visual Studio Code  
**Язык реализации:** TypeScript

## Описание

При работе с исходным кодом часто возникает необходимость привести имена переменных и функций к единому стилю. Плагин CaseConverter автоматизирует этот процесс для выделенного фрагмента кода или отдельного идентификатора.

В отличие от простых генераторов сниппетов, плагин использует алгоритм контекстного маскирования. Это означает, что строковые литералы и комментарии остаются нетронутыми, а изменения применяются исключительно к именам переменных в самом коде. Также плагин защищает ключевые слова языка от случайного изменения.

## Для кого этот плагин

Плагин будет полезен следующим категориям пользователей:

- **Разработчикам при рефакторинге:** при приведении старого кода к единому корпоративному стандарту (например, при переходе проекта с `snake_case` на `camelCase`).
- **Программистам-полиглотам:** при переносе логики из одного языка в другой, где приняты разные стили именования (например, из C++ в JavaScript).
- **Студентам и учащимся:** для быстрого форматирования кода под требования преподавателя или методички.
- **Командам на код-ревью:** для быстрого исправления имен переменных, не соответствующих общему стилю проекта, без ручной перепечатки.
- **Специалистам по конфигурациям:** для изменения стиля ключей в JSON или YAML файлах.

## Возможности

- Поддержка четырех стилей именования: camelCase, snake_case, PascalCase, kebab-case.
- Обработка целых блоков кода: плагин находит все идентификаторы в выделении и конвертирует их.
- Умное маскирование: содержимое строк (`"..."`, `'...'`) и комментариев (`//`, `/* */`) не изменяется.
- Защита синтаксиса: встроенный список зарезервированных слов (C/C++/JS) предотвращает поломку кода.

## Установка

1. Скачайте файл `case-converter-0.0.1.vsix` из раздела релизов (или соберите его самостоятельно командой `vsce package`).
2. Откройте VS Code, перейдите в раздел расширений (Extensions).
3. Нажмите на меню `...` в правом верхнем углу панели расширений и выберите пункт "Установить из VSIX..." (Install from VSIX...).
4. Выберите скачанный файл.

## Использование

1. Откройте файл с исходным кодом (например, `.cpp`, `.js`, `.ts`).
2. Выделите переменную или целый блок кода.
3. Нажмите `Ctrl+Shift+P` (или `Cmd+Shift+P` на macOS) для открытия палитры команд.
4. Введите `CaseConverter` и выберите необходимый стиль из списка:
   - `CaseConverter: to camelCase`
   - `CaseConverter: to snake_case`
   - `CaseConverter: to PascalCase`
   - `CaseConverter: to kebab-case`

### Пример работы

**Исходный код (до преобразования в camelCase):**
```cpp
int item_count = 5;
// item_count остается неизменным в комментарии
std::cout << "item_count = " << item_count;
```

**Результат (после преобразования в camelCase):**
```cpp
int itemCount = 5;
// item_count остается неизменным в комментарии
std::cout << "item_count = " << itemCount;
```

## Документация

Подробная документация API, сгенерированная с помощью TypeDoc, находится в папке `docs`. Для просмотра откройте файл `docs/index.html` в любом браузере.

## Ограничения

- Поддерживается только латиница (A-Z, a-z).
- Аббревиатуры не распознаются как отдельные слова (например, `HTTPServer` будет преобразовано в `httpserver`).
- Список зарезервированных слов ориентирован в первую очередь на C/C++ и базовый JavaScript.
